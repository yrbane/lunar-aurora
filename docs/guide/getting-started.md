# Getting Started

Bienvenue dans la documentation de **Lunar Aurora**.

## Installation

Via CDN (pour le prototypage rapide) :

```html
<link rel="stylesheet" href="https://unpkg.com/lunar-aurora@latest/dist/aurora.min.css">
```

Via NPM :

```bash
npm install lunar-aurora
```

Puis importez le CSS :

```css
@import 'lunar-aurora/dist/aurora.min.css';
```

## Utilisation de base

Lunar Aurora utilise des classes utilitaires et des composants sémantiques.

```html
<button class="la-btn primary">Click me</button>
```
